# Environmental Intelligence Lab (EIL)

This is a static GitHub Pages site for the Environmental Intelligence Lab at the University of Bristol.

## Uploading to GitHub Pages

Upload the **contents of this folder** to the root of the Pages repository. The repository must contain `index.html` at its top level, alongside `style.css`, the other HTML pages, and the `assets` folder.

If the repository already contains an older version, replace the old files rather than adding this folder beside them. This prevents an old homepage and the new homepage from being served together.

The public navigation is: Research, Projects, Team, Publications, News, and Join us. The EIL logo returns to the landing page.
